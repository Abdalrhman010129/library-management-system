# Library Management System

A C++ and SQL desktop application designed to manage library operations efficiently, featuring automated search filters and secure data records.

## Tech Stack
* **Language:** C++
* **Database & Logic:** SQL, Microsoft Access & VBA

## Key Features
* Custom search functionality to reduce book retrieval time.
* Secure user records and inventory status management using SQL DDL/DML.
* Modular architecture following clean code principles.
